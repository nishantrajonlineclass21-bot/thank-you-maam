# Namrata Ma'am Tribute

## Folder
```
namrata-tribute/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── namrata-maam.jpg   <- PUT HER PHOTO HERE (portrait, 3:4 works best, under ~500 KB)
    └── music.mp3          <- optional; the music button hides itself if this is missing
```
Until the photo is added, the frame shows a placeholder note.

## Deploy on GitHub Pages
1. Create a new public repo (e.g. `thank-you-maam`) and upload all files, keeping the `assets` folder.
2. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main`, folder `/ (root)` -> Save.
3. After a minute your site is live at `https://<username>.github.io/thank-you-maam/`.
